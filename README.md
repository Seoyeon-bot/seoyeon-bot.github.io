# Personal Portfolio Website

This is my personal portfolio website. It includes information about me, my education, skills, experience, and projects.

## Features

- About me section
- Education and experience section
- Skills list
- Project cards with links
- Simple responsive layout for mobile and desktop

## Built With

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this project.
2. Open the project folder.
3. Open `index.html` in your web browser.
